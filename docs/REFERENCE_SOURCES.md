# Approved reference sources

This file is the canonical allowlist of external fiction/media sources that Open Fufu design may draw from for character identities, thematic references, quotation-derived names, Challenge Mode concepts, Echo candidates, Origin concepts, and similar reference-driven content.

## Ownership boundary

- This file owns only **which source IPs/franchises are approved reference material**.
- Inclusion here does **not** approve any particular character, quote, Echo, Origin, trait, Challenge opponent, mechanic, or implementation.
- Specific Echo identities and rules remain owned by [`ECHO_CATALOGUE.md`](./ECHO_CATALOGUE.md).
- Normal Official Origin content remains owned by [`OFFICIAL_ORIGINS.md`](./OFFICIAL_ORIGINS.md) and [`ORIGIN_TRAIT_CATALOGUE.md`](./ORIGIN_TRAIT_CATALOGUE.md).
- Official-AI architecture/configuration remains owned through [`official-ai/README.md`](./official-ai/README.md).
- Challenge Mode mechanics and roster rules must have their own canonical owner when that post-v1 subsystem is formalized; this catalogue does not define Challenge Mode.

## Catalogue rules

- Keep **one entry per source IP/franchise**, not one entry per season, cour, film, OVA, or adaptation installment.
- The initial seed was bootstrapped from the supplied MyAnimeList completed-list capture, taking entries with a user score **greater than 4**. This records bootstrap provenance, not a claim that the current catalogue exhausts the entire MyAnimeList account.
- Explicitly approved manual exceptions may be included regardless of that bootstrap score threshold.
- Once a source is listed here, this file is the authority. The catalogue is not dynamically synchronized to MyAnimeList and a later rating change does not silently add or remove a source.
- New sources may be added directly when explicitly approved; they do not need to originate from MyAnimeList.
